# Трекер привычек

Лабораторная работа №4. Вариант 38.

## Описание

Консольное приложение для отслеживания привычек. Позволяет вести учёт выполнения
нескольких привычек, добавлять новые, отслеживать серии и получать мотивационные фразы.

## Структура проекта

- `main.py` — основной файл с логикой программы
- `habits_data.py` — модуль с данными (привычки, отметки, мотивации)
- `requirements.txt` — список зависимостей
- `tests/test_habits.py` — тесты PyTest

## Доступные команды

| Команда | Описание |
|---------|----------|
| `list` | Показать список привычек |
| `done <номер>` | Отметить выполнение |
| `skip <номер>` | Пропустить привычку |
| `status <номер>` | Показать статистику |
| `add <имя>` | Добавить новую привычку |
| `active` | Привычки с выполнениями |
| `today` | Выполнено сегодня |
| `marks` | История отметок |
| `motivation` | Случайная мотивационная фраза |
| `help` | Справка |
| `exit` | Выход |
