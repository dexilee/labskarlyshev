# Трекер привычек

Лабораторная работа №3. Вариант 38.

## Описание

Консольное приложение для отслеживания привычек. Позволяет вести учёт выполнения привычек, 
отслеживать серии и получать мотивационные фразы.

## Структура проекта

- `main.py` — основной файл с логикой программы
- `habits_data.py` — модуль с данными (привычки и мотивации)
- `requirements.txt` — список зависимостей

## Доступные команды

| Команда | Описание |
|---------|----------|
| `list` | Показать список привычек |
| `done <номер>` | Отметить выполнение |
| `skip <номер>` | Пропустить привычку |
| `status <номер>` | Показать статистику |
| `motivation` | Случайная мотивационная фраза |
| `help` | Справка |
| `exit` | Выход |
